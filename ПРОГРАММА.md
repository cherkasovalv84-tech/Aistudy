# Предобучение. Старт и база
- Что такое вайбкодинг простыми словами: программирование через общение с ИИ, фокус на продукте, а не на синтаксисе.
- Какие проекты реально собрать новичку: лендинги, боты, мини-приложения.
- Регистрация и подготовка инструментов: Google Gemini, Google AI Studio, Lovable AI, Claude Code.
- Что такое сервер и API простыми словами.
**Результат:** Понимание логики вайбкодинга и готовность создавать первые проекты.

# Модуль 1. Создание сайтов
- Генерация структуры через ИИ.
- Добавление контента и настройка стилей.
- Адаптация под мобильные устройства.
- Мини-анимации.
- Инструменты: GitHub, Vercel, Render.
- Проверка продакшн-версии.
**Результат:** Первый опубликованный сайт.

# Модуль 2. Первый AI-проект
- Google AI Studio: настройка модели.
- Генерация интерфейса и подготовка структуры проекта.
- Экспорт и публикация.
**Результат:** Первый рабочий AI-проект в портфолио.

**Результат:** Несколько серьезных проектов для портфолио.
